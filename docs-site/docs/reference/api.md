# Public API Reference

:::info Coming soon
Tracked by [issue #109](https://github.com/geekshiv/rikugan/issues/109) — public API with dedicated API-token support. Not yet built.
:::

Until #109 ships, every endpoint documented in this site is authenticated the same way the frontend is (session cookie) or, for CI ingestion, the workspace API key described in [Workspaces & API Keys](../admin/workspaces-and-api-keys.md). A dedicated, publicly documented API-token surface with its own docs (auth, rate limits, versioning) will replace this placeholder once #109 lands.

In the meantime, the live OpenAPI UI at `/docs` on your own backend deployment reflects the current, real endpoint set.
